# სავარაუდო დიაგნოზის პროგნოზირების გაუმჯობესება

პროექტის ბოლო ვერსიაში სისტემა აღარ არის მხოლოდ ზოგადი რისკის მაჩვენებელი. მოდელი პაციენტის ადრეულ კლინიკურ მონაცემებზე დაყრდნობით პროგნოზირებს სავარაუდო გულ-სისხლძარღვთა დიაგნოზის ჯგუფს, რომელიც MIMIC-IV მონაცემებში ICD კოდებით არის დაფიქსირებული.

სწორი ფორმულირებაა:

> სისტემა პროგნოზირებს სავარაუდო ICD-კოდირებულ გულ-სისხლძარღვთა დიაგნოზის ჯგუფს და არა ექიმის საბოლოო დიაგნოზის ჩანაცვლებას.

## ტექნიკური ცვლილება

თითოეული subtype მოდელისთვის დაემატა ცალკე დიაგნოსტიკური threshold. Threshold-ები დათვლილია validation split-ზე F1-ის მაქსიმიზაციით. თუ პაციენტის probability შესაბამის threshold-ს აჭარბებს, სისტემა ამას აჩვენებს როგორც სავარაუდო დიაგნოზის ჯგუფს. თუ probability threshold-ს უახლოვდება, მაგრამ არ აჭარბებს, შედეგი აღინიშნება როგორც საზღვრული დიაგნოსტიკური სიგნალი.

## ინტერპრეტაცია

მოდელი გაწვრთნილია რეალურ hospital admission-ებზე და სამიზნე ნიშნები მიღებულია `diagnoses_icd.csv.gz` ფაილიდან. ამიტომ პროგნოზი დაკავშირებულია რეალურად დაფიქსირებულ ჰოსპიტალურ დიაგნოზებთან. მიუხედავად ამისა, შედეგი არ ნიშნავს, რომ სისტემამ საბოლოო დიაგნოზი დასვა. მოდელი აჩვენებს, რომელ დიაგნოზის ჯგუფს უჭერს მხარს არსებული მონაცემები და რას უნდა მიაქციოს ექიმმა ყურადღება.

## ვებაპლიკაციაში დამატებული შედეგები

API და frontend ახლა აბრუნებს:

- diagnosis probability;
- diagnosis threshold;
- diagnosis status;
- მოკლე კლინიკურ ინტერპრეტაციას;
- 2-3 მთავარ განმსაზღვრელ ფაქტორს;
- ექიმისთვის გადასამოწმებელ დამატებით კვლევებს.

## დამატებითი სიმპტომების ტექსტური ველი

დამატებითი სიმპტომების ველი გაუმჯობესდა ისე, რომ სისტემა აღარ ეყრდნობა მხოლოდ ბრმა keyword matching-ს. ტექსტი იყოფა წინადადებებად და თითოეული სიმპტომისთვის ფასდება კონტექსტი:

- დადებითი სიმპტომი, მაგალითად: „აქვს გულმკერდის ტკივილი“;
- უარყოფილი სიმპტომი, მაგალითად: „უარყოფს გულმკერდის ტკივილს“ ან „ქოშინი არ აქვს“;
- წარსული/ისტორიული სიმპტომი, მაგალითად: „წარსულში ჰქონდა გულმკერდის ტკივილი“;
- გაურკვეველი სიმპტომი, მაგალითად: „შესაძლოა აქვს ქოშინი“.

მოდელში დადებით symptom feature-ად გადადის მხოლოდ ის სიმპტომი, რომელიც ტექსტში ამჟამინდელ დადებით ნიშნად არის აღწერილი. უარყოფილი, წარსული ან გაურკვეველი სიმპტომები frontend-ში ჩანს, მაგრამ არ უთანაბრდება ავტომატურად დადებით კლინიკურ ნიშნას.

ეს ცვლილება პროექტს უფრო ახლოს აყენებს რეალურ დიაგნოსტიკურ ამოცანასთან, მაგრამ ინარჩუნებს აკადემიურად სწორ შეზღუდვას: საბოლოო გადაწყვეტილება ეკუთვნის ექიმს.
